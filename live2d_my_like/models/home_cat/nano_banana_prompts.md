# 用 Gemini（nano banana）重繪 kuroneko_00.png 的操作流程

## 為什麼要拆成 4 塊，而不是整張丟進去

`kuroneko_00.png` 是一張 2048×2048 的 Live2D 貼圖 atlas，裡面有 30 多個彼此獨立、大小形狀完全不同的小色塊（頭、耳、尾、四肢、鼻子、瞳孔…）。圖片生成模型在處理「一整張密集小圖」時，很容易：

- 把相鄰的小色塊誤判成同一個物件而融合在一起
- 移動、縮放、旋轉某些色塊
- 把透明背景誤填成白色或雜色
- 邊緣模糊、破洞、跟原本的鋸齒毛邊對不齊

一旦發生上述任何一種情況，這張貼圖在 Live2D 裡就會**位移、破圖、對不上 Mesh**，那些改動是無法用肉眼小修修好的。

所以真正安全的做法是「兩階段」：

1. **交給 nano banana 的只有「上色」這個任務**，而且拆成 4 個象限（已經幫你切好在 `_source_crops/` 資料夾）分開處理，降低它同時要顧到的物件數量。
2. **色彩生成完之後，一定要跑 `apply_alpha_mask.py`**，這支腳本會強制把 AI 生成圖的顏色「套用回」原始貼圖的透明遮罩、尺寸、位置——不管 nano banana 實際畫成什麼樣子，最終輸出檔的每個 Piece 邊界、透明範圍、大小位置都會跟原檔逐像素一致。這是保證「Mesh/UV/Piece 位置」100% 不變的關鍵步驟，靠 AI 自己是做不到這個精確度的。

## 素材位置

- 待重繪的 4 張分割圖：`home_cat\_source_crops\quadrant_TL_head_back.png`、`quadrant_TR_face_tail.png`、`quadrant_BL_muzzle_legs.png`、`quadrant_BR_legs_ears_paws.png`
- 六張參考照片：`C:\question\cat_data\`（全部 6 張都上傳，不要只挑一張）
- Piece 對應表與色票：`texture_piece_map.md`（跟這份文件放在一起）

## 操作步驟

1. 打開 Gemini，選擇支援圖片編輯的模型（nano banana / Gemini 2.5 Flash Image）。
2. 每一次對話，**同時上傳**：① 一張 `_source_crops` 分割圖　② 全部 6 張貓咪照片。
3. 貼上對應的提示詞（見下方，四段各自獨立）。
4. 產出後檢查：透明背景是否還在、每個色塊的形狀/大小/位置跟原圖是否一致（可以疊圖比對）。不滿意就在同一個對話串接著說「XX部位再調整」，nano banana 支援多輪修改。
5. 把四張結果依原檔名存到 `home_cat\_nano_banana_output\`（自己建立這個資料夾），檔名對應：
   - `quadrant_TL_head_back.png`
   - `quadrant_TR_face_tail.png`
   - `quadrant_BL_muzzle_legs.png`
   - `quadrant_BR_legs_ears_paws.png`
6. 回來這個對話跟我說「生成完了」，我會幫你跑 `apply_alpha_mask.py` 把四塊拼回 2048×2048、套用原始透明遮罩，輸出最終的 `kuroneko_00.png`。（如果你想自己跑，腳本用法寫在檔案最下面。）

   都已經跟動畫骨架綁定，絕對不能改變。

   你的任務只有一件事：把每個色塊「表面的顏色與花紋」，換成我附上的真實貓咪照片裡那隻貓的顏色與花紋

   - 保留原圖現有的立體感畫法（漸層陰影＋高光），只是改變色相/花紋，不要換成平塗或改變筆觸風格
   - 圖片輸出尺寸必須跟輸入完全一致

## Piece 4 (象限) 各自的提示詞

### TL：頭後/後腦（quadrant_TL_head_back.png）
```
這個色塊是貓的頭部後側/雙頰（大型渾圓毛絨形狀，左右各有一個膨出的臉頰）。
依照片：
- 底色改為溫暖橘黃（亮部 #E0954F，陰影 #A85F30）
- 加上鯖魚虎斑（直條紋，非漩渦花紋），顏色約 #8B4A24，左右對稱
- 額頭區域的條紋要在頭頂中央收攏成清楚的「M」字形（參考照片正臉特寫）
- 雙頰的條紋方向由眼角往耳朵方向放射
```

### TR：臉正面＋尾巴＋眼睛＋牙齒（quadrant_TR_face_tail.png）
```
這張裡有多個色塊，分別處理：

1. 左上的盾形/心形色塊＝臉部正面：底色橘黃＋鯖魚虎斑，中央從額頭到鼻頭上緣要有一條白色細中線
   （鼻樑白線），白線兩側各有一道深色八字形條紋夾住（參考正臉特寫照片）。下巴尖端轉白色。
2. 中間的長條彎曲形狀＝尾巴：這隻貓的尾巴沒有任何一張照片拍到，所以請你依照這張貓身體上的虎斑
   間距、方向，合理延伸出「環狀虎斑」（一圈一圈環繞尾巴的深色條紋），不要自己發明照片中不存在的
   花色（例如不要加白色尾尖）。環紋疏密比照頭部/身體條紋的疏密。
3. 右側小三角綠色圓形＝眼睛虹膜：把綠色改成琥珀金／深黃棕色（約 #C99A3E~#B8860B），參考照片裡
   的眼睛顏色。瞳孔（如果在這張裡）維持深色不動。
4. 白色牙齒、鬍鬚線稿：維持原樣不動。
```

### BL：口鼻＋前肢＋鼻子＋前掌（quadrant_BL_muzzle_legs.png）
```
這張裡有多個色塊，分別處理：

1. 左上大橢圓（口鼻/下顎，中央有蝴蝶形陰影）：中央改白色（延續鼻樑白線），兩側虎斑，陰影對應
   照片中鼻樑兩側的八字條紋。
2. 右上三角形＝耳朵外側：改成橘色（同頭部橘色），耳緣顏色略深。
3. 中間錐狀直筒＝前臂上段：上半段虎斑環紋，靠近腳踝處漸變成白色（白襪的起點）。
4. 小型黑色鼻子形狀（含鼻孔亮部）：整個改成鮭魚粉／粉紅色（約 #E8A0A0），鼻孔部分顏色更深的粉紅。
5. 粉色橢圓片：維持粉色，微調色相貼近照片中的鼻樑/嘴唇粉色即可。
6. 左下長條形＝前肢下段：上段虎斑、下段轉白色，白色/虎斑交界要跟前臂上段（第3項）銜接一致，
   不要出現色塊邊界處花紋斷裂。
7. 下方帶趾間分隔線的掌形＝前掌：改成白色（白襪），趾間肉球維持粉色。
8. 右下弧形色塊＝身體側面：延續身體虎斑條紋方向。
```

### BR：後腿＋耳朵＋掌＋舌頭（quadrant_BR_legs_ears_paws.png）
```
這張裡有多個色塊，分別處理：

1. 左上並排兩個錐狀色塊＝後腿：依身體虎斑推估環狀虎斑（照片中後腿大多被遮擋，所以用前腿花紋的
   疏密當參考，左右兩腿花紋必須對稱一致）。
2. 兩個小深色橢圓（夾在後腿中間）＝瞳孔：維持深色不動，形狀不動。
3. 右側兩對三角形＝耳朵（外側+內側各一對）：外側三角改橘色，內側三角改成淡粉膚色（約 #E8B8B0，
   比現在的粉紫色更偏膚色，參考照片耳內顏色）。
4. 中間帶趾間分隔線的掌形＝前掌：改白色＋粉色肉球。
5. 上方與中間的淺灰弧線簇＝眉毛/頸部絨毛：可維持淺灰，或改成極淺橘白色，不要大幅更動。
6. 粉色梯形＝舌頭：維持不動。
7. 左下雙峰形色塊＝臀部：延續身體側面虎斑。
8. 右下堆疊兩個掌形（含肉球）：改白色＋粉色肉球。
```

## 完成後：合併 + 套用透明遮罩（UV 安全網）

把 nano banana 產出的 4 張圖存到 `home_cat\_nano_banana_output\`（檔名見上方步驟 5），然後執行：

```
python apply_alpha_mask.py
```

腳本會：
1. 讀取 `home_cat\kuroneko_00.png`（原始檔，只用來取尺寸與透明遮罩，不會被覆蓋）
2. 把 4 張生成圖依原始象限位置拼回 2048×2048
3. 用原始貼圖的 Alpha 通道，強制蓋掉生成圖的 Alpha（生成圖只提供 RGB 顏色）
4. 輸出成新檔 `home_cat\kuroneko_00.png`（依你的要求，直接輸出到 home_cat，不覆蓋 kuroneko 原始資料夾）
5. 印出檢查報告：輸出尺寸是否為 2048×2048、透明像素數量是否與原檔一致

這樣即使 nano banana 畫出來的邊緣跟原圖有些微落差，最終檔案的透明範圍/Piece 邊界仍然會被強制拉回跟原檔逐像素相同。
