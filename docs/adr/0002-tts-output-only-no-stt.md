# 語音只做輸出（TTS），v1 不做語音輸入（STT）

「語音」需求原本涵蓋輸入與輸出。決定 v1 只做輸出——角色用 OpenAI TTS 把回覆念出來；使用者輸入維持純文字（點角色開輸入框）。STT 需要處理喚醒詞、降噪、麥克風權限等額外複雜度，且跟「即時對話」的文字輸入框（見 CONTEXT.md「即時對話」）不是同一個工程量級。之後若要加語音輸入，是獨立的後續功能，不影響現有文字輸入的架構。

> v1 之後，語音輸入確實作為獨立後續功能加回來了——見 ADR-0007。這份 ADR 保留當時「先不做」的理由紀錄，不代表決定是錯的，只是範圍到此為止。
