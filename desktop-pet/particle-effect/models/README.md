# 3D 模型檔（GLB）放這裡

這個資料夾裡的 `.glb` **不跟著 git 版本走**（見根目錄 `.gitignore`：私人收集的遊戲資源、檔案動輒 10MB 以上、授權來源不明）。
從 git 拿到專案時，這裡只會有這份說明，**模型要另外取得**。

## 缺檔時會看到什麼

- 啟動桌寵時系統匣跳出「缺少 3D 模型檔」提示，終端機也會列出缺哪些檔。
- 系統匣「光粒子特效」選單裡，缺檔的模型標示「（缺模型檔）」，無法選取。
- 一個模型檔都沒有時，「開啟」會停用；開機預設顯示 3D 模型的設定也會暫時失效。
- 如果檔案壞掉或讀取失敗，模型的位置會顯示紅色的「MISSING MODEL FILE」粒子字樣。

## 怎麼補上

1. 檢查缺哪些檔：

   ```bash
   cd desktop-pet
   npm run check-assets
   ```

   會列出 `particle-effect/sources.json` 裡每個缺檔模型的檔名（`file` 欄位）。
2. 向專案維護者索取這些 GLB，或者換成你自己的模型：系統匣右鍵 →「模型設定...」→「3D 模型」分頁按「＋ 新增模型」選 GLB，檔案會自動複製到這個資料夾、加進清單（參數說明見 `particle-effect/動畫參數說明.md`）。
3. 檔案放進來就會生效，選單上的「缺模型檔」會自動消失，不用重開桌寵。

`npm run dist` 打包前也會自動檢查一次；缺檔只會警告、不會中斷打包，但打出來的 `.exe` 裡就不會有那些模型。
